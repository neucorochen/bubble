## Реализовано локально

- Общая светлая Aero-оболочка обычных маршрутов: стеклянная рамка, декоративные кнопки окна, синяя шапка, единый фон, панели и системные кнопки. Авторизация сохраняет отдельную компоновку с той же палитрой.
- Прокручивается документ, полоса прокрутки у края viewport. Рамка фиксированная, верхние элементы sticky; нижняя горизонтальная рамка скрыта. В `App.tsx` обработчик прокрутки обновляет CSS-параметры обрезки содержимого, чтобы оно не проходило поверх стекла.
- Единая конфигурация меню: Профиль, Лента, Поиск, Сообщения, Группы, События. Маршрут событий остаётся `/notifications`. Desktop, нижняя панель и бургер-меню используют одну конфигурацию; гостям доступны обзор, регистрация и вход.
- PNG-иконки навигации переиспользуются во всех вариантах меню. Общий компонент бренда использует новый логотип, сохранено название Bubble; favicon и существующие PWA-иконки обновлены.
- Декоративные акценты используют общий светло-зелёный токен `#bfec67`; цвета ошибок и опасных действий не заменялись.
- Основной интерфейс переведён на русский; относительное время использует `Intl.RelativeTimeFormat`, склонения — общую утилиту. Известные ошибки API переводятся на клиенте, неизвестные показываются нейтрально с HTTP-кодом; исходный текст хранится в объекте ошибки для диагностики. Исчерпывающая проверка всех состояний перевода не подтверждена.
- Лента открывается на подписках; все записи доступны второй вкладкой. Сохранены запросы, кеши и пагинация. В главном Composer скрыты платные поля и видимый счётчик, но лимиты и поддержка платных записей в остальных местах сохранены.
- Карточки ленты используют ширину под аватаром; удаление с подтверждением находится сверху справа. Время ведёт на отдельную страницу записи; аватары записей и комментариев ведут в профиль.
- Встроенные комментарии лениво монтируются при первом раскрытии, анимируются за 180 мс, сохраняют черновик. Закрытый блок получает `inert`; предусмотрен reduced motion.
- Встроенная и отдельная форма комментария используют однострочный input, кнопку «Отправить» и отключённую кнопку фото с подсказкой о будущей функции. API получает только текст.
- Desktop/mobile выход требует подтверждения через `window.confirm`; подписи нативных кнопок зависят от браузера.
- Общая правая колонка содержит заглушки сбора на сервер и дневника разработки; гостям показывается только дневник, ссылки «Обзор» / GitHub Bubble и динамический год. RSS убран из правой колонки, но маршрут News сохранён, как и Plus / Contact.
- Фон коротких страниц заполняет viewport; вкладки групп переиспользуют стили ленты. У сообщений форма и заголовок остаются видимыми, история прокручивается внутри диалога.

## Проверки и ограничения

UI-исправления после коммита `ba718a0`: шапка с отдельными сжимаемыми колонками, подписи меню с 1100 px, мобильные вкладки с границами, Aero-fallback в `index.html`, видимый контраст активного «Обзора». Блок дохода в профиле скрыт стилем, компонент и данные сохранены. Для Firefox добавлен локальный fallback без blur на фиксированной рамке; его влияние на мерцание не подтверждено реальной прокруткой Firefox.

Мобильная компоновка теперь используется до 1100 px включительно, desktop — с 1101 px. Для локальной диагностики Firefox доступен `?aeroDebug=1`: четыре независимых переключателя отключают фильтры, градиенты, тени/псевдоэлементы и фиксированную рамку. Без параметра панель и её диагностические атрибуты отсутствуют. Причина мерцания пока не подтверждена; проверка реального Firefox остаётся открытой.

Для проверки мерцания в Firefox дополнительно отключено размытие закреплённых вкладок и мобильной панели, а фон содержимого упрощён до непрозрачного Aero-градиента. Результат требует ручного подтверждения в Firefox; диагностический режим сохранён.

Ручной тест пользователя: достаточно общего переключателя теней/псевдоэлементов. Он сохранён для контрольного сравнения; добавлены независимые box-shadow, text-shadow, ::before и ::after (псевдослои фиксированной рамки по-прежнему исключены). В Firefox удалена только внешняя тень всей страницы; тень окна сохранена. Это кандидат исправления, причина ещё не установлена. Переключатель «Firefox: вернуть тень всей страницы» позволяет сравнить результат; затем нужно по отдельности проверить четыре новых переключателя при выключенном общем.

Следующий ручной тест подтвердил отсутствие мерцания при отключении всех box-shadow (включённый возврат тени страницы перекрывается этим правилом). В Firefox размытая внешняя тень фиксированной рамки заменена тонким контуром; внутренний блик, тени карточек и кнопок сохранены. Это адресный кандидат, результат ещё не подтверждён. В диагностике добавлены группы теней рамки, шапки/кнопок окна, боковых панелей/вкладок/нижнего меню и drawer/PWA, а также возврат размытой тени рамки для сравнения. Обычное оформление Chromium не меняется.

Текущее решение после дальнейшей проверки: Firefox-only отключение всех box-shadow внутри .aero-app, включая псевдоэлементы и состояния hover/focus, по аналогии с подтверждённым пользователем диагностическим правилом. Это перекрывает прежние кандидаты теней; границы, градиенты и text-shadow сохранены. Chromium не затронут, диагностическая панель оставлена. Playwright Firefox вне песочницы захватил промежуточные кадры непрерывной прокрутки страницы, временно удлинённой DOM-копиями карточек до 13290 px; разрывы на снимках есть в обоих режимах, поэтому причину и устранение мерцания этот захват не подтверждает. Нужна проверка обычного Firefox без диагностических галок.

В предыдущих этапах проходили web typecheck, CSS-парсинг и `git diff --check`. Проводились точечные проверки Chrome с имитацией API на desktop/mobile, включая навигацию, пустую ленту, вкладки, комментарии, подтверждение выхода и компоновку сообщений.
Последняя быстрая проверка иконок/логотипа/зелёного токена выполнена на 1440 и 390 px: битых изображений и горизонтального переполнения не обнаружено.
Это не заменяет проверку реального приложения и не подтверждает готовность всех маршрутов.
